Composer profiles

SYNC.PLANNER adapts to any type of professional composer. Here's how the app naturally fits each profile.

🎼
Library Composer
Produces thematic albums for multiple publishers simultaneously. Manages briefs with deadlines, validates track by track.
Album = Publisher brief
🎬
Film Composer
Composes for a film or series. Each project has a unique title, a director/producer as client, and a delivery deadline.
Album = Film title
🎮
Video Game Composer
Composes the soundtrack for a game. The project title = the game name. Tracks correspond to scenes, levels or ambiances.
Album = Game name
💡 Whatever the profile, it works the same way — one project = one commission, with tracks to produce, a deadline and an associated client.
🔄

Full workflow

From receiving a brief to final delivery — here's how SYNC.PLANNER supports every step.

1
Create the project
Click "+ New project". Enter the title (e.g. "Neon Horizon", "The Big Blue", "Shadow Realm"), the client/publisher, deadline and expected number of tracks.
2
Add information
Use 🔗 Links to centralise reference files (Dropbox, Drive...), 📝 Notes for client instructions, and 🖼️ Cover to add a visual cover.
3
Compose and update statuses
For each track: move the status from "Composing" → "Sent" → "Mix" → "Validated" or "Delivered". The progress bar updates automatically.
4
Monitor deadlines
🔔 alerts flag urgent projects. The Calendar view shows all deadlines for the month. The Dashboard displays projects by urgency.
5
Archive and recycle
Once delivered, archive the project to keep the view clean. Refused tracks can be marked available and reused in another project.

Archiving

Completed projects can be archived to keep the main view clean, without losing data.

📦
Archive — Project options → "Archive". The project disappears from the main view but remains accessible via the "Archived" filter.
↩️
Unarchive — An archived project can be made active again at any time.
💡 Archived projects remain counted in global statistics and production history.
♻️

Track recycling

A refused track is not lost. It can be marked available and transferred to another project.

1
Mark as available
On a refused track, click "Available". It appears in 🔔 alerts with an orange badge.
2
Transfer
Click 🔀 → choose an existing album or create a new one → confirm the transfer.
3
History preserved
The track shows "(created for Album X)" to keep track of its origin.

Assistant IA

SYNC.PLANNER can connect to Claude, GPT-4o or Mistral via personal API key to create projects, update statuses or analyse production in plain language.

⚠️ Optional feature — Requires an account and API key from the chosen provider. Usage consumes tokens billed directly by the provider. Conversations are not saved between sessions.
1
Create an API key
console.anthropic.com (Claude) · platform.openai.com (GPT-4o) · console.mistral.ai (Mistral)
2
Configure in the app
Tab 🤖 → select provider → paste API key → click "Test".
3
Example usage
"Create a Sony Music album with 8 tracks deadline September 30th" → the album is created instantly in the app.

Installation — Mac

SYNC.PLANNER is available as a .dmg file for Intel Mac (x64). Compatible with macOS 10.13+.

1
Download
From syncplanner.app, click "Mac — Download".
2
Open the DMG
Double-click the .dmg, then drag SYNC.PLANNER to the Applications folder.
3
Launch
Open SYNC.PLANNER from Applications or Launchpad.
⚠️ macOS security alert — If macOS blocks the app: right-click → "Open" → "Open Anyway". This step is only required once.
🖥️

Installation — Windows

SYNC.PLANNER is available as a .exe installer for Windows 10/11 (x64).

1
Download
From syncplanner.app, click "Windows — Download".
2
Install
Double-click SYNC.PLANNER Setup 1.0.0.exe and follow the steps.
3
Launch
SYNC.PLANNER is accessible from the desktop or Start menu.
