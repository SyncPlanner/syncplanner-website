Guide d'utilisation

Tout ce qu'il faut savoir pour utiliser SYNC.PLANNER au quotidien.

Rechercher : ⌘+F ou Ctrl+F
👤

Profils compositeurs

SYNC.PLANNER s'adapte à tout type de compositeur professionnel. Voici comment l'app se configure naturellement selon le profil.

🎼
Compositeur Library
Produit des albums thématiques pour plusieurs éditeurs simultanément. Gère des briefs avec deadline, valide track par track.
Album = Brief éditeur
🎬
Compositeur Film
Compose pour un film ou une série. Chaque projet a un titre unique, un réalisateur/producteur comme client, et une deadline de livraison.
Album = Titre du film
🎮
Compositeur Jeux Vidéo
Compose la bande sonore d'un jeu. Le titre du projet = le nom du jeu. Les tracks correspondent aux scènes, niveaux ou ambiances.
Album = Nom du jeu
💡 Peu importe le profil, le fonctionnement est identique — un projet = une commande, avec des tracks à produire, une deadline et un client associé.
🔄

Workflow complet

De la réception d'un brief à la livraison finale — voici comment SYNC.PLANNER accompagne chaque étape.

1
Créer le projet
Cliquer sur "+ Nouveau projet". Renseigner le titre (ex: "Neon Horizon", "Le Grand Bleu", "Shadow Realm"), le client/éditeur, la deadline et le nombre de tracks attendues.
2
Ajouter les informations
Utiliser 🔗 Liens pour centraliser les fichiers de référence (Dropbox, Drive...), 📝 Notes pour les instructions du client, et 🖼️ Cover pour ajouter une pochette visuelle.
3
Composer et faire avancer les statuts
Pour chaque track : faire passer le statut de "Composition" → "Envoyée" → "Mix" → "Validée" ou "Livrée". La barre de progression se met à jour automatiquement.
4
Surveiller les deadlines
Les alertes 🔔 signalent les projets urgents. La vue Calendrier montre toutes les deadlines sur le mois. Le Dashboard affiche les projets par ordre d'urgence.
5
Archiver et recycler
Une fois livré, archiver le projet pour garder la vue propre. Les tracks refusées peuvent être marquées disponibles et réutilisées sur un autre projet.
🎵

Relance éditeur

SYNC.PLANNER vous alerte automatiquement quand un éditeur tarde à répondre — que ce soit sur un album entier ou sur une track spécifique.

Relance par album

Dans chaque projet, la section Relance éditeur vous permet de renseigner la date de votre dernier contact avec l'éditeur et le délai avant alerte (ex: 15 jours). Si l'éditeur ne répond pas dans ce délai, une alerte rouge apparaît dans le Briefing.

Relance par track

Chaque track dispose de sa propre date de relance dans la colonne de droite. Vous pouvez définir un délai personnalisé par track. L'indicateur passe en rouge 🚨 quand le délai est dépassé.

Réponse reçue

Quand l'éditeur répond, cliquez sur ✅ Réponse reçue — un popup s'ouvre pour saisir la date de réponse. L'alerte disparaît immédiatement. Vous pouvez réinitialiser si besoin.

Email automatique de relance

Envoyez un email de relance professionnel en un clic — avec l'objet, le corps et la signature pré-remplis automatiquement.

Comment ça marche

Sur chaque track, un bouton ✉️ Envoyer email de relance apparaît. En cliquant, votre client mail s'ouvre avec :

  • L'adresse email de l'éditeur pré-remplie
  • L'objet : Relance — Nom de la track / Nom de l'album
  • Le corps du message avec le nom du contact et votre signature

Client mail

Dans Paramètres → Client mail, choisissez votre client mail préféré :

  • 📬 Mail.app — ouvre directement Apple Mail avec tout pré-rempli
  • 📧 Gmail — nécessite de configurer Gmail comme client mail par défaut dans Chrome
  • 📋 Copier — copie le mail dans le presse-papier
💡 Si l'email de l'éditeur n'est pas renseigné, un popup vous propose de l'ajouter directement — il sera automatiquement sauvegardé dans la fiche éditeur.

Paramètres

La page Paramètres centralise toutes vos préférences personnelles — profil, client mail et modèle d'email.

👤 Profil compositeur

Renseignez vos informations personnelles : prénom, nom, structure, téléphone, site web. Ces informations servent à signer automatiquement vos emails de relance.

✉️ Client mail

Choisissez comment envoyer vos emails de relance : Mail.app, Gmail ou Copier dans le presse-papier.

📝 Modèle de mail

Personnalisez le texte de vos emails de relance en FR et EN. Utilisez les variables {contact} {track} {album} pour personnaliser chaque email automatiquement.

💡 Un bouton ↩ Restaurer le texte par défaut vous permet de revenir au modèle original à tout moment.

Archivage

Les projets terminés peuvent être archivés pour garder la vue principale propre, sans perdre les données.

📦
Archiver — Options du projet → "Archiver". Le projet disparaît de la vue principale mais reste accessible via le filtre "Archivés".
↩️
Désarchiver — Un projet archivé peut être remis en actif à tout moment.
💡 Les projets archivés restent comptabilisés dans les statistiques globales et l'historique de production.
♻️

Recyclage de tracks

Une track refusée n'est pas perdue. Elle peut être marquée disponible et transférée vers un autre projet.

1
Marquer comme disponible
Sur une track refusée, cliquer "Disponible". Elle apparaît dans les alertes 🔔 avec un badge orange.
2
Transférer
Cliquer sur 🔀 → choisir un album existant ou créer un nouveau → confirmer le transfert.
3
Historique conservé
La track affiche "(créée pour Album X)" pour garder la trace de son origine.
🎁 Bonus optionnel

Assistant IA

SYNC.PLANNER peut se connecter à Claude, GPT-4o ou Mistral via clé API personnelle pour créer des projets, modifier des statuts ou analyser la production en langage naturel.

⚠️ Fonctionnalité optionnelle — Nécessite un compte et une clé API chez le fournisseur choisi. L'utilisation consomme des tokens facturés directement par le fournisseur. Les conversations ne sont pas conservées entre les sessions.
1
Créer une clé API
console.anthropic.com (Claude) · platform.openai.com (GPT-4o) · console.mistral.ai (Mistral)
2
Configurer dans l'app
Onglet 🤖 → sélectionner le fournisseur → coller la clé API → cliquer "Tester".
3
Exemple d'utilisation
"Crée un album Sony Music avec 8 tracks deadline 30 septembre" → l'album est créé instantanément dans l'app.

Installation — Mac

SYNC.PLANNER est disponible en fichier .dmg pour Mac Intel (x64). Compatible macOS 10.13+.

1
Télécharger
Depuis syncplanner.app, cliquer sur "Mac — Télécharger".
2
Ouvrir le DMG
Double-cliquer sur le .dmg, puis glisser SYNC.PLANNER dans le dossier Applications.
3
Lancer
Ouvrir SYNC.PLANNER depuis Applications ou le Launchpad.
⚠️ Alerte sécurité macOS — Si macOS bloque l'ouverture : clic droit sur l'app → "Ouvrir" → "Ouvrir quand même". Cette étape n'est nécessaire qu'une seule fois.
🖥️
